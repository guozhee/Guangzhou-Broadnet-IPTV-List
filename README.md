## 怎么用

抓到的是**组播地址**，绝大多数播放器不能直接播 `rtp://`，需要先转成 HTTP 单播。两种常见做法：

### udpxy（简单）

```sh
udpxy -a 0.0.0.0 -p 8888 -m <IPTV网口>
```

然后播放地址变成：

```
http://<路由IP>:8888/rtp/225.1.101.138:11111
```

### rtp2httpd（推荐）

功能更全（FCC 快速换台、FEC 纠错、M3U 直接托管），适合长期使用。把 `channels.m3u` 里的 `{udpxy}` 换成 rtp2httpd 的地址即可。

## 前提条件

不是拿到地址就能播，还差这几步：

1. **必须是广州广电（珠江宽频）在网用户**，地址只在自家专网内有效
2. **软路由要能进 IPTV 专网**。常见做法是光猫 IPTV 口直连软路由的一个网口，把这个口配成 IPTV 网段的静态地址
3. 那个 IP 最省事的获取方式：打开机顶盒 → 设置 → 网络信息，记下 IP、掩码、网关，抄到软路由上
4. 网口配好后，udpxy / rtp2httpd 指定这个口作为组播源

> 如果你是多业务融合光猫（上网和 IPTV 走同一根线），需要按 VLAN 拆开，光猫里能查到 IPTV 的 VLAN ID。

## 抓包方法

大致流程，细节各家光猫不同：

1. 软路由上把 IPTV 网口和接机顶盒的网口**桥接**起来，让机顶盒的流量经过软路由
2. `tcpdump` 抓包，同时在机顶盒上**逐个换台**——每换一个台就会发一次 IGMP 加入，组播地址就在里面
3. 从抓包里提取 `239.x` / `225.x` 段的组播地址，和频道名对上

频道名和地址的对应关系，可以看机顶盒换台时请求的节目单，或者手动记录。
